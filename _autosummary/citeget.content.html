citeget.content

citeget.content¶

Main-article extraction: strip site chrome from HTML before it becomes Markdown.

The default extractor, main_content(), is a “readability-lite” scorer built on beautifulsoup4 (already a dependency): it drops navigation-like elements, then picks the block with the most paragraph text. Any callable html -> html can replace it (the extractor seam); trafilatura_extractor() is an optional, stronger one (Apache-2.0, pip install trafilatura).

Web Archive copies are cleaned by clean_wayback(): the toolbar/banner is dropped and web.archive.org/web/<ts>/ link prefixes (absolute, relative or protocol-relative) are rewritten back to the original URLs. This applies in every content mode, full included.

Also here, because the extractor needs them: page_title() (the page’s title, with a Title – Site site name removed by strip_site_name()) and unwrap_layout_tables() (tables used for page layout become plain blocks; data tables are left alone).

>>> html = "<body><nav>Menu</nav><div><p>" + "Real text. " * 20 + "</p></div></body>"
>>> "Menu" in main_content(html), "Real text." in main_content(html)
(False, True)

citeget.content.clean_wayback(html)[source]¶

Drop the Wayback Machine toolbar/banner and un-prefix archived links.

>>> h = '<a href="https://web.archive.org/web/2020/http://x.org/a">a</a>'
>>> clean_wayback(h)
'<a href="http://x.org/a">a</a>'
>>> clean_wayback('<div id="wm-ipp-base">Dec JAN Feb</div><a href="/web/2015/http://x.org/">x</a>')
'<a href="http://x.org/">x</a>'
Return type:

str

citeget.content.drop_junk_lines(markdown)[source]¶

Remove rule-only / empty-bullet lines and unwrap one-cell table rows.

Fenced code blocks are left alone. Blank lines are kept (they separate paragraphs). A thematic break (***, ---, * * *) standing alone between two paragraphs is a scene break, and is kept.

>>> drop_junk_lines("| hello |\n| --- |\n* \n\ntext")
'hello\n\ntext'
>>> drop_junk_lines("one\n\n***\n\ntwo")
'one\n\n***\n\ntwo'
Return type:

str

citeget.content.main_content(html)[source]¶

The HTML of the block that most likely holds the article body.

Drops chrome, picks the candidate block with the most paragraph text, adds same-kind sibling blocks holding prose (an article split into sections), trims breadcrumbs and promo boxes from their edges, and leads with the article’s headline when the block left it behind.

Return type:

str

citeget.content.page_title(html, *, url='')[source]¶

The page’s own title: og:title, <title>, else the first <h1> that is not a site logo.

A site name joined to it (Title – Site) is removed, using the page’s og:site_name, its ``<h1>``s and the url’s path to tell which part is the site (see strip_site_name()).

>>> page_title("<title>Hackers and Painters</title>")
'Hackers and Painters'
>>> page_title('<title>Fire and Motion – Joel on Software</title>')
'Fire and Motion'
>>> page_title("<p>no title here</p>") is None
True
Return type:

Optional[str]

citeget.content.strip_site_name(title, *, site_names=(), article_titles=(), url='')[source]¶

The article’s part of a Title – Site (or Site – Title) title.

Segments matching one of site_names (og:site_name, application-name) go first. Of the rest, one matching one of article_titles (the page’s <h1>``s, ``<title>) wins, then one spelled out by the url’s path (/reading-code-is-like-...); otherwise the first segment is kept, which is the usual order. A title with no separator comes back as it is.

>>> strip_site_name("Reading Code is Like Reading the Talmud – Joel on Software")
'Reading Code is Like Reading the Talmud'
>>> strip_site_name("Roger Federer as Religious Experience - Tennis - The New York Times")
'Roger Federer as Religious Experience'
>>> strip_site_name("Joel on Software - Fire and Motion", site_names=["Joel on Software"])
'Fire and Motion'
>>> strip_site_name("Hacker News | Show HN: A thing", article_titles=["Show HN: A thing"])
'Show HN: A thing'
>>> strip_site_name("Stack Overflow - How do I X", url="https://so.com/q/1/how-do-i-x")
'How do I X'
>>> strip_site_name("Beating the Averages")
'Beating the Averages'
>>> strip_site_name("Rust vs. Go - A Comparison", article_titles=["Rust vs. Go - A Comparison"])
'Rust vs. Go - A Comparison'
Return type:

str

citeget.content.unwayback_url(url)[source]¶

Strip a Wayback prefix from url, giving back the original URL.

>>> unwayback_url("https://web.archive.org/web/20150308214418/http://a.com/x")
'http://a.com/x'
>>> unwayback_url("/web/20150308214418im_/http://a.com/p.png")
'http://a.com/p.png'
>>> unwayback_url("//web.archive.org/web/2015/mailto:me@a.com")
'mailto:me@a.com'
>>> unwayback_url("http://a.com/x")
'http://a.com/x'
>>> unwayback_url("/web/2019/")  # a site's own /web/ section, not a capture
'/web/2019/'
Return type:

str

citeget.content.unwrap_layout_tables(html)[source]¶

Rewrite tables used for page layout as plain <div> blocks.

A table is layout when it nests another table, or when its cells hold prose (see _is_layout_table()). Data tables, header cells or a grid of short values, are left intact, so they still become Markdown tables.

>>> unwrap_layout_tables("<table><tr><td><p>An essay.</p></td></tr></table>")
'<div><div><div><p>An essay.</p></div></div></div>'
>>> unwrap_layout_tables("<table><tr><td>1</td></tr></table>")
'<table><tr><td>1</td></tr></table>'
Return type:

str
